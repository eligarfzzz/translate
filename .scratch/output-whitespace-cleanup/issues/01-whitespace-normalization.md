# 01: 净化闸门空白规范与空节点去除

**What to build:** 模型回显的译文经过净化闸门写入译文节点前，得到完整的空白卫生处理——元素边界的换行/缩进不再以视觉空白上屏、行内相邻文字不粘连、空壳元素不出现在译文中、pre/code 内部代码原样、表格结构不错位。规则全部收敛在净化闸门内（危险属性清洗之后、序列化返回之前），banned 标签删除与危险属性清洗的既有行为完全不变。

**Blocked by:** 无

**Status:** ready-for-agent

- [ ] 空白字符全集覆盖空格/tab/换行/回车/`\f`/`\v` + NBSP + 零宽 `\u200B-\u200D` + BOM `\uFEFF`；`&nbsp;`/`&#10;`/`&#9;`/`&#x200B;` 实体形式输入同样被清理（实体经解析后归一为真实字符，无需实体层特判）
- [ ] 纯空白文本节点：邻接块级边界侧删除，位于行内内容之间时折叠为单个普通空格（`Hello <b>bold</b> world` 不粘连成 `Hellobold`）
- [ ] 非纯空白文本节点只 trim 首尾：块边界侧删净、行内邻接侧保留单空格；节点中部空白序列不压缩
- [ ] 块级/行内上下文按 HTML 默认展示语义的块级标签集合判定（净化在离线解析文档上进行，取不到页面样式）；集合外元素（含未知/自定义标签）一律按行内保守处理，宁可少删
- [ ] 空元素（无元素子、无清理后非空文本子）自底向上删除；`<br>` 等 void 元素保留，模型用其表达的换行仍生效；链式空壳（空 `ul` 内空 `li`）逐层清空
- [ ] 表格结构（table/tr/td/th 及表头族）空壳保留，不错位塌陷
- [ ] pre/code 子树整体豁免：内部换行、缩进、注释原样保留（与 prompt 模板「只译注释」约束同源）
- [ ] 文本清理与空元素清理都只在净化闸门内生效，输入侧快照/骨架序列化（不做空白压缩、保护缩进结构）完全不动
- [ ] 测试覆盖 spec Testing 清单全部用例项（块间空白删、行内保空格、实体空白、空元素/链式空壳、空表格保留、pre/code 原样、中部空白不压缩、br 保留）
- [ ] 既有净化测试（script/iframe 移除、on* 属性、javascript: URL、正常标签保留）回归全绿
