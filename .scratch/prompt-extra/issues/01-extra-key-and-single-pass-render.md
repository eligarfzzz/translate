# 01: 追加提示词接缝——`extra` 键、`{extra}` 占位符、单遍替换

**What to build:** 默认提示词模板在「Output exactly one translated copy of that fragment.」与「Example: Input: …」之间多出一个 `{extra}` 占位符，它的内容来自新配置键 `extra`（UI 标签「追加提示词」），默认空串。用户填了追加提示词，模板里那一行就变成他写的内容；没填就是一行空行。追加提示词里写的 `{target}`、`{host}`、`{extra}` 一律**字面保留**——不是靠"哪个键先替换"这种隐式顺序，而是靠 `renderPrompt` 改为**只扫描模板一次**：任何替换结果都不再被扫描。这同时修掉一个真问题：注入进模板的宿主 HTML 与目标语言文本，此前会被二次扫描，网页正文里若含字面 `{target}` 就会被替换成「中文」。

本票同时按用户决策改造占位文字的守门测试：**删掉「凡默认值为空串的字段都必须配示例」**（示例是可选字段知识，不是新增字段的强制税），改为通用断言「默认值非空的字段，占位文字恒等于默认值本身」。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 默认值表新增 `extra: ""`（追加提示词）；不新增任何判空分支——字符串规则自动适用（trim 后非空才落盘，空值不落盘、读取回退空串，内部换行保留）。
- [x] 默认模板在「Output exactly one translated copy of that fragment.」与「Example: Input: …」之间插入**裸 `{extra}` 独占一行**；该位置由按行定位的用例守住（不写死整篇模板文本）。
- [x] `renderPrompt` 改为**单遍替换**：一次扫描模板 + 查表取值（`{host}` 仍是特例，注入时包一层 `<html>…</html>`），查不到的占位符原样保留，替换值不再进入扫描；返回值用函数形式给出，避免 `$&` 之类替换串特殊语法。签名的对外形态不变。
- [x] 字面保留有用例守住：追加提示词的值里含 `{target}` / `{host}` / `{extra}` 时全部原样出现在渲染结果里。
- [x] 不再二次扫描有用例守住：宿主 HTML 里含字面 `{target}` 时保持原样（这是本票修掉的真问题）。
- [x] 既有渲染行为逐条不变且有断言：缺 `{host}` 抛错、未知占位符（如 `{entries}`）原样保留、不传 vars 时 `{target}` 原样、宿主换行原样保留、`<html>` 包装协议。
- [x] 后台代理渲染调用传入 `extra: cfg.extra`；既有模板兜底（非空且含 `{host}` 才用存储值）保持不变。
- [x] 占位文字守门改造：**删除**「默认值为空串的字段都必须配占位示例」；**保留**「示例清单里的键其默认值必须是空串」；**新增**"默认值非空的字段占位恒等于默认值本身"的通用循环断言；`EMPTY_DEFAULT_PLACEHOLDERS` 与三个 API 字段的假值示例保持原样（零痕迹），`extra` **不配**示例。
- [x] 配置测试补 `extra` 的判空用例行（空串 / 纯空白 / 非字符串为空；trim 后落盘；含内部换行的多行内容保留换行）与默认值快照 `extra: ""`；`mergeConfig` 的整包对比用例随之通过。
- [x] `npm test` 全绿（lint + node:test）；除本票明确改写的守门用例与占位取值用例外，任何既有行为断言都不得被放宽。
