# 02: 空框显示默认值占位，「恢复默认」改为清空

**What to build:** 配置页任何空输入框都用灰色占位文字告诉用户"留空会得到什么"：目标语言显示「中文」、并发上限显示 20、提示词模板显示内置默认模板的全文；默认值本就是空串的端点/密钥/模型显示描述性假值示例。点「恢复默认」不再把当前默认值写进输入框（那等于把用户冻结在这一版默认上），而是清空该组输入框——占位文字随即出现，用户看到"将使用默认值"，点保存后该组键从存储中消失，从此永远跟随版本默认。

**Blocked by:** 01（空即未设置的读写语义）

- [x] 端点/密钥/模型三项默认值为空串，占位显示描述性示例，且必须是明显的假值以延续零痕迹默认（沿用 `example.com` / `sk-example…` / `example-model` 一类写法），不得出现任何真实端点、凭证或厂商模型名。
