# 04: 收回权威——同一条字段规则不再有第二份实现

**What to build:** 工单 01–03 建立了"判空只有一处实现"的权威，但那道权威只覆盖到"存什么"；凡是需要**解释**或**展示**这条规则的地方，都各自又抄了一份。本票把这三份副本收回配置模块：配置页对"哪些字段、什么算空、占位显示什么"变成零了解，只调用配置模块给出的结论。

具体是四件独立的小事，合起来的效果是"改规则只需改一处，漏改会被测试拦住"：

1. **模板缺占位符的判定收回权威**。今天配置页为了决定保存后说哪句话，自己重抄了一遍"trim 后非空且含占位符"的判断，并且把"只有提示词模板需要占位符"这个知识也一并抄了过去。收回后：配置模块导出"某字段的原始值是否因缺占位符而被判空"的判定函数；配置模块内部的归一化实现改为调用这个函数——即该判断在配置模块内也只有一处；配置页改用该函数决定文案。判定函数与归一化结果必须永远一致，由表驱动测试锁死。

2. **占位文字的字段知识收回配置模块**。今天配置页持有一张"默认值为空串时显示什么示例"的字段名清单，与配置模块的默认值表并列。收回后：示例清单与默认值表同处配置模块；配置模块导出"取某字段占位文字"的取值函数（默认值非空 → 默认值本身；默认值为空串 → 示例；两者都无 → 空串，绝不产出字面量 `undefined`）；配置页只剩一次调用。空串默认值仍需一份额外文本，因此这是"同模块共处 + 单一取值函数"，不是字面意义上的一张表。

3. **补两条守门断言**，让上面两条的"漏改"变成可发现的失败：
   - 占位覆盖：默认值为空串的字段必须都有示例；示例清单里的每个键，其默认值必须是空串。
   - 字段清单包含关系：配置页表单里的字段必须都在默认值表的键里（这条守着保存反馈里"本次删除了 N 项"这个计数的前提）。

4. **保存反馈不再吞信息**。今天模板缺占位符时走专门文案，把"下一次翻译生效"和"其中 N 项为空"都替换掉了：用户清空一整组字段、同时又填了个缺占位符的模板时，只会看到模板那一句，其余被删的项数不见了。收回后：专门文案与计数叠加（例如"提示词模板缺 {host}，视为留空未保存；另有 N 项为空，已删除设置、回退默认"），两条信息都在。
