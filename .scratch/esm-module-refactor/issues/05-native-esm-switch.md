# 05: 原生 ESM 换轨（原子票）——依赖关系搬进代码本身

**What to build:** 模块依赖从三张互不相干的清单（内容脚本数组、service worker 的脚本导入、配置页标签顺序）搬进代码里的 `import` 语句。双环境导出包装、全局赋值、全局符号契约测试、vm 沙箱装配一并消失。扩展行为完全不变，且扩展刚注入完就右键也能生效（不再有那一次静默无反应）。任意网页无法用固定 URL 探出扩展是否安装。仍然零构建：`chrome://extensions` 里加载的目录就是仓库目录，改完刷新即可。

**这是原子票，不可再切**：lib 一旦成为 ESM，三个消费端必须同时改，中间态无法绿。

**Blocked by:** 01（**已满足**：真机实测完成，地基成立但需降级——不启用 `use_dynamic_url`）、03（路径已稳定）、04（工厂形态已就位，本票只需把启动方式换成加载器）

**Status:** done（已实施：d71531f + 修复 68190de；真机验收两条待人工）

- [x] 全部源码为 ESM，包管理声明切到模块模式；三种双环境导出写法与全部全局赋值删除
