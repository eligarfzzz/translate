# 02: 统计并展示每条缓存的命中次数

**What to build:** 在票 01 的完整查看路径上增加命中统计。每条缓存从写入时的零次开始，每次真实命中回放加一；列表消息把次数带给设置页，表格新增「命中次数」列。旧条目和覆盖写有明确、可验证的兼容语义。

**Blocked by:** 01（依赖分页表格和列表消息）

**Status:** resolved

- [x] 新键写入次数为零，真实缓存命中加一，未命中不增加；次数与最后使用时间在同一次命中事务中保存。
- [x] 缺少次数字段的旧条目按零显示，首次命中后变为一，不追溯历史。
- [x] 覆盖已有键时保留已有次数；清空、过期或淘汰后同键重建从零开始。
- [x] 列表响应和设置页表格展示每条累计次数，不增加全局命中率或未命中统计。
- [x] 存储测试覆盖递增、旧字段兼容、覆盖写保留、删除后重建；background 测试通过真实命中后再查询验证统计；设置页测试验证次数列。
- [x] 移除递增或把覆盖写改成清零时，对应测试必须转红。
- [x] 命中回放、会话重用和端口协议不变；完整测试与 lint 通过。
