# 01: 设置页分页查看短文本缓存

**What to build:** 打通从设置页表格到 background 再到 IndexedDB 的完整读取路径。用户进入「通用」TAB 后能看到全部缓存的骨架原文、原始回显和最后使用时间，按最后使用时间倒序，每页二十条，并可前后翻页。关闭缓存开关仍能查看，清空后表格立即刷新。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 表格位于「通用」TAB，不是表单字段，不参与保存，不写配置。
- [x] 展示整库条目，不按当前配置指纹过滤，缓存关闭时仍可读取。
- [x] 原文与原始回显按纯文本显示，缓存中的标签不会成为设置页元素。
- [x] 每页二十条，按最后使用时间倒序；显示当前页、总页数、总条数，并提供边界正确的翻页控制。
- [x] 空库显示明确空状态；越界页归一到有效页；读取失败显示失败提示，不伪装成空库。
- [x] 每次进入「通用」TAB 读取第一页，手动清空成功后回到第一页重新读取。
- [x] 存储查询复用现有索引和主键，不重复保存原文；background 提供独立的列表请求—响应消息。
- [x] 存储、background、设置页三层测试覆盖上述行为，内存 IndexedDB 替身具备实际用到的倒序和分页能力。
- [x] 既有翻译、命中、清空、清理和内容脚本协议不变；完整测试与 lint 通过。
