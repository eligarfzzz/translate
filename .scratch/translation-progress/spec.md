# Spec: 翻译进度徽标——视口右下角的会话进度悬浮显示

Status: ready-for-agent

## Problem Statement

一次会话里，宿主经并发池逐个请求，译者只能看着译文节点一段段冒出来，对「一共多少段、已经翻完几段、有没有失败」毫无感知。长页面动辄几百个宿主，点下翻译后不知道还要等十秒还是十分钟，也不知道结束时是不是有宿主悄悄失败了——错误标记散落在各宿主的译文节点里（斜体红字），不滚到那一屏根本看不见。

## Solution

视口右下角悬浮一枚**进度徽标**（`position: fixed`，不随滚动移动），会话期内实时显示：

```
10% 100/1000(1100)(1)
```

- `100/1000`：**排除边缘区域**（翻译优先级的档 2：header/footer/nav/aside 及等效 role）的 已完成/总数。边缘区域被排到请求队尾，计入进度只会让前期百分比失真。
- `(1100)`：含边缘区域的全部宿主总数。
- `(1)`：出错的宿主数；**无错误时整个括号不显示**。
- 百分比 = 已完成/总数（排除边缘区域），**向下取整**——只有真正全部完成才显示 100%。
- 每有一个宿主流**落定**（定稿 / 失败 / 连接中断 / 空译文），已完成数 +1 并重算百分比。

计数规则（已与 owner 拍板）：

- **出错的流也计入分子**：它确实结束了；同时错误数 +1。否则只要有 1 个错，进度永远到不了 100%。
- **空译文回退不回退分子**：净化为空时译文节点被移除、宿主之后会被重扫重翻；已 +1 的分子不回退，重翻落定再 +1（重发现时分母同样再 +1）。
- **显示/隐藏时机**：点「翻译」时出现并保持（100% 后也留着，作为完成确认），点「还原」时移除。

徽标自身是扩展注入物：绝不成为宿主、绝不触发重扫（与译文节点同等待遇）。

## User Stories

1. 作为长文页面的读者，我希望点下翻译后立刻看到总数与实时进度，这样我知道还要等多久。
2. 作为读者，我希望进度分母不含页眉页脚导航，这样百分比反映的是我正文的阅读进度，不被队尾的边缘区域拖慢观感。
3. 作为读者，我希望能瞥见含边缘区域的总规模，这样我知道页面一共要翻多少段。
4. 作为读者，我希望有宿主失败时能看到错误计数，这样结束时我知道有几段没翻成，而不是滚到那一屏才发现红字。
5. 作为读者，我希望没有错误时不显示错误括号，这样正常路径的界面是干净的。
6. 作为读者，我希望失败的宿主也计入已完成数，这样 1 个失败不会让进度永远卡在 99%。
7. 作为读者，在 SPA / 懒加载页面里，我希望重扫发现新宿主后总数随之增长，这样进度始终反映「目前已知的全部工作量」。
8. 作为读者，我希望 100% 后徽标仍然保留，这样我有一个明确的「全部翻完」确认信号。
9. 作为读者，我希望点「还原」后徽标随译文节点一起消失，页面回到一字未动的原状。
10. 作为读者，我希望徽标固定在视口右下角、不随页面滚动移动，这样我随时能瞥到它。
11. 作为读者，我希望徽标不拦截鼠标点击，这样它不遮挡正文上的链接与按钮。
12. 作为读者，我希望徽标自身不会被拿去翻译、不会因为自身内容变化触发新一轮扫描，这样它既不出现在译文里也零请求开销。
13. 作为读者，我希望百分比向下取整，这样看到 100% 就意味着真正全部落定，没有四舍五入的虚报。
14. 作为扩展 owner，我希望计数状态的收口与「每宿主流落定」的唯一收口点（端口流程的 settle）共用，这样不存在第二条会忘记同步的计数路径。
15. 作为扩展 owner，我希望徽标模块是会话四块之外的第五块、环境显式注入，这样 jsdom 沙箱可以直接驱动它。
16. 作为扩展 owner，我希望徽标样式硬编码内联（与译文节点同款做法），不进配置中心、不上配置页。
17. 作为扩展 owner，我希望「还原移除注入物」的语义覆盖徽标，这样还原后 DOM 与翻译前完全一致的安全边界不被打破。

## Implementation Decisions

- **新模块：进度徽标工厂**（会话装配的第五块，与 render/translate/observer 平级），依赖单向、环境（document）显式注入。接口四个方法：`show()`（建节点上屏）、`addHosts(translatable, all)`（本轮发现的 排除边缘档宿主数 / 全部宿主数，累加进分母）、`settled(errored)`（落定 +1，`errored` 为真时错误数 +1）、`remove()`（摘节点、计数清零）。计数与文案渲染全部收在模块内部，调用方不碰格式。
- **文案格式**：`<pct>% <done>/<total>(<totalAll>)`，错误数 > 0 时追加 `(<errors>)`；`total` 为 0 时百分比按 0 显示（不产 NaN）。每次计数变化即重渲染。
- **计数的两个注入点**：宿主发现出口按档分计数（档 2 计入 `all` 不计入 `translatable`），首轮与重扫共享同一出口；落定回调挂在端口流程的 settle 唯一收口（每宿主恰好一次），`errored` 覆盖三条失败路径（error 消息 / 空回显「未返回译文」/ 连接意外中断）。净化为空导致的静默移除**不算错误**，但仍算落定。
- **徽标元素**：`div.translate-progress` 附加到 `document.body`，内联样式硬编码——fixed 右下角、半透明深底浅字、小号等宽数字、圆角、`pointer-events: none`、最高档 z-index。样式表与译文节点同款常量做法；不用 Shadow DOM（与全扩展一致）。
- **自排除**：硬跳过选择器表追加 `.translate-progress`（徽标本身含文本且是 body 直接子级，不堵这个口它有成为宿主的资格路径）；观察器对徽标子树的节点新增/属性变化与 `.translate-node` 同等忽略——徽标每次重渲染都改 DOM，不忽略则每次进度跳动都白排一轮防抖。
- **生命周期挂接**：「翻译」消息路径上会话开启成功后 `show()`；还原路径 `remove()`（与停动画、清译文节点同列）；会话拒绝重入时不重复 show。
- **CONTEXT.md 要动**：新增「进度徽标」词条；「译文节点 is the only mutation」规则改写为「译文节点与进度徽标是仅有的页面注入物」，还原规则同步覆盖徽标。
- **不写 ADR**：三条门槛一条不中——可随时删模块回退，无不可逆决策。

## Testing Decisions

- **只有一道缝**：内容脚本沙箱（tests 既有基建：消息与端口输入 → DOM 输出，可控时序 mock 端口 + 手动时钟）。断言落在文档里的徽标元素文本上，不断言模块内部计数器。
- **沿用既有夹具**：content-sandbox 的 jsdom 环境、几何补丁、mock 端口原样复用；不新建夹具、不改既有用例。
- 覆盖分支：
  - 混合档位页面：分母排除边缘档、括号内为全部宿主数；
  - 定稿落定 +1 与向下取整（如 1/3 → 33%）；
  - error 消息路径：分子 +1 且错误括号出现、计数正确；
  - 无错误时错误括号不显示；
  - 重扫新增宿主：分母与括号同步增长；
  - 还原：徽标从文档中移除；
  - 徽标自排除：进度跳动不产生额外端口、不触发额外重扫（在途端口数即观测量）。
- 先红后绿：新用例在未接线的代码上应失败（没有徽标元素），接线后转绿。

## Out of Scope

- **交互**：徽标不可点击，不提供「查看失败列表」「重试失败宿主」等入口。
- **自动隐藏**：100% 后不做淡出/收起；唯一移除路径是还原。
- **配置化**：开关、位置、样式一律不暴露配置项。
- **速率/耗时**：不显示每秒段数、预计剩余时间。
- **跨会话持久化**：进度随会话生灭，不留存。
- **Shadow DOM 样式隔离**：与全扩展现状一致，不引入。

## Further Notes

- 并发池下定完成序不定，分子跳动无序属预期；百分比只在 settle 时变化。
- 重扫使分母增长时百分比会**下降**（如 90/100 → 90/150），这是「进度反映已知全部工作量」的直译，不是回归。
- 空译文静默移除的宿主重翻时会再次计入分母与分子，进度可能短暂超过之前的完成数观感——这是「不回退」规则的直接推论，已与 owner 确认。
