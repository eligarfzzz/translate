# Spec: 宿主即请求——废除批次合并，一宿主一请求并发直发

## Problem Statement

现行设计（ADR-0001）把宿主合并成批：每批一个 prompt、条目靠行首 `[N]` 标记切分。这引入了条目对齐这一整层协议复杂度——标记错位、漏条目、模型把标记写进正文等风险全部由此而来；批次同时是失败粒度（一批失败殃及 20 个宿主）。属性（class/id/href/src）随宿主 HTML 原样投喂，token 开销大且给模型篡改属性的机会；input/button 等表单标签出现在投喂内容里，模型回显它们会在译文节点里产生可交互元素。

## Solution

**宿主即请求**：每个最小翻译单元（宿主）独立发起一次端点请求，无条目、无标记协议——prompt 是翻译指令 + 该宿主的**骨架 HTML**（只有标签名与内容）。回显全文即该宿主译文，流式直通。并发池控制同时在途请求数，默认 20、配置页可调。失败粒度细化到单宿主。

## User Stories

1. 作为页面读者，每个段落独立请求翻译，任何一段的对齐/错位问题都不可能波及其他段落。
2. 作为页面读者，单个请求失败只影响那一个宿主，显示该宿主的错误提示，其余照常。
3. 作为扩展 owner，我可以通过配置页调整并发池上限（默认 20），控制对网关的压力。
4. 作为扩展 owner，投喂内容只有标签与文本（无任何属性），请求 token 显著下降，模型无从篡改 class/href。
5. 作为页面读者，按钮文字（input 的 value、button 的内文）以普通文本形式被翻译。
6. 作为页面读者，译文节点里不会出现 input/button 等可交互元素（换名为 span）。
7. 作为页面读者，流式体验保持：请求进行中看到剥标签的纯文本预览，完成时定稿为净化后的 HTML。
8. 作为页面读者，还原/会话外安全边界不变。
9. 作为扩展维护者，批次构造与条目装配的切分逻辑彻底删除，`[N]` 协议相关代码与测试不复存在。
10. 作为扩展维护者，配置项 `batchSize`、`maxCharsPerBatch` 连同配置页字段、README、测试全部清除。
11. 作为扩展维护者，pre/code 裸块（无外层可翻文本）整段静默跳过，与纯码包裹层语义统一。
12. 作为扩展维护者，此决策以新 ADR 记录并标注取代 ADR-0001 的分批部分（流式部分仍有效）。

## Implementation Decisions

- **序列化管线**（snapshotHtml 演进，顺序）：克隆宿主 → 剔除译文节点 → 媒体 8 标签转同名空占位（既有）→ `input`/`button` 换名为 `span`（input 的 value 转为文本、button 子内容保留）→ 剥离全部元素属性（仅留标签名与文本内容）。
- **pre/code 排除**：宿主候选自身为 PRE/CODE 时不具资格——裸放/嵌套的 pre 段整段静默跳过，与"纯码包裹层判空剪枝"统一。
- **请求协议**：prompt = 翻译指令模板 + 单宿主骨架 HTML；无标记、无条目拼接。回显全文即译文：流式 delta 直接预览（剥标签文本），done 时定稿（净化后写入）。
- **并发**：既有 runPool 语义保留，limit = `concurrency`，默认值 4→20。
- **删除**：`batching.js` 及其测试、条目装配器的切分逻辑（流式直通职责并入或简化保留）、config 的 `batchSize`/`maxCharsPerBatch`、options 页对应字段、提示词模板中的标记协议条款（第 5 条改写为单段指令）。
- **净化闸门保持**：sanitize 不放松（防模型幻觉注入属性/脚本），只是投喂侧已无可复制的属性。
- **新 ADR-0005**：记录"宿主即请求"决策及动因（消灭对齐协议层、失败粒度细化），标注 ADR-0001 的分批部分作废、流式部分延续。

## Testing Decisions

- 接缝 1（纯函数）：序列化断言——属性全剥、`<a class=x href=y>T</a>` → `<a>T</a>`、input/button 换名与 value 转文本、媒体占位回归、裸 pre 跳过、混合段回归。
- 接缝 2（集成 harness）：单请求协议（一次 translate = N 个独立端口请求，N=宿主数）、并发上限（同时在途端口 ≤ 配置值）、单请求失败只标记该宿主、会话外安全边界回归。
- 既有测试：prompt/config/装配器相关用例随协议改写或删除；宿主发现/脱敏/净化保持绿。
- Prior art：tests/host-discovery.test.js、tests/content-rescan.test.js（mock 端口基建）。

## Out of Scope

- 请求合并/去重的任何回归（本 spec 就是废除合并）。
- 译文节点内链接/高亮的还原（属性已剥，回显天然无 href/class——接受）。
- 回显净化侧新增媒体/表单禁令（既有防护保持）。
- 已翻宿主追加内容重翻（既有盲区）。
- 僵尸 context script 自清理（此前已决定不修）。

## Further Notes

- 每请求携带完整指令头部是固有开销；网关侧可观察请求数上升（页面宿主数 × 1）。
- CONTEXT.md「翻译批次」词条将改写为「并发池」语义，「宿主」词条补 pre/code 排除。
